# Intent-Driven Development Finds Its Home at intentfile.org

Intent-Driven Development now has an open, vendor-neutral home: [intentfile.org](https://intentfile.org).

For decades, enterprise software has been trapped between two extremes - hand-written code that drifts from the business it was meant to serve, and heavyweight modelling tools that were too costly to author. Intent-Driven Development takes a different position: **business knowledge is the source of truth, and it should be captured as intent** - a single, readable, declarative artefact from which the running application is generated deterministically.

That idea now has a dedicated home. [intentfile.org](https://intentfile.org) hosts the **Intent File Specification** - a precise, vendor-neutral description of the `.intent` format: the entities, relations, processes, forms, reports, roles and declarative glue that make up a whole application, one altitude above the models a generator produces from it. The specification belongs to no single vendor and is free for anyone to read, implement and build on.

This is a call for collaboration. Whether you build platforms, generators, tooling, or the enterprise systems that run on them, you are welcome to join the effort - read the specification, put it to work, and help refine it. The more implementations and perspectives it gathers, the stronger and more useful the standard becomes.

We believe intent is the right altitude for enterprise software, and we are proud to help drive this initiative forward. Explore the specification at [intentfile.org](https://intentfile.org) and join us in shaping what comes next.
